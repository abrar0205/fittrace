# Datasets and provenance

The four tracks below are kept separate. Only track 1 is loaded.

**Why there is no real gap data.** Calibrated panel-gap measurements (images with a known mm scale and reference values) are produced inside car plants and their suppliers and are not published. None of the public datasets below contains them. The simulator exists so that every number in FitTrace can be checked against an exact ground truth; it is labelled as simulated everywhere it appears.

## 1. Calibrated synthetic inspection images with simulated production (loaded)

- **Source:** generated by this repository (`fittrace.simulation`), MIT licence.
- **Versions:** `panel-gap-generator/2.0.0` (colour, painted panels), `biw-gap-simulator/1.0.0`, seed `20260214`.
- **Content:** 560 units on one simulated line: body-in-white stations S10, S20 and S30 (fixtures FX-101/102, FX-201/202/203; nutrunners NR-301/302), the S40 paint shop (booths PB-401/402; seven invented paint codes) and S50 end-of-line inspection (colour camera CAM-501). Each unit has 2 colour inspection images (480 × 240 px, 0.025 mm/px) at locations FD-FF-M (nominal 4.0 ± 0.5 mm) and FD-RD-M (4.5 ± 0.5 mm).
- **Delivery:** two increments (units 1–480, then 481–560) plus a deliberately truncated copy of the second increment. This exercises a successful import, an unchanged re-delivery (skipped), a failed delivery (checksum mismatch) and an incremental load.
- **Injected data-quality defects:** 1% of rows (missing timestamps, malformed numbers, out-of-range readings, unknown station codes, orphan serials, exact duplicates), counted in `manifest.json`. Integration tests reconcile the rejects against these counts.
- **Injected fault (ground truth):** fixture FX-202 shifts laterally by +0.42 mm from unit SIM-00265. It is logged as a "locator pin replaced" changeover event and stored in `fault_injections`.

## 2. Carparts-Seg (documented, not integrated)

- **Reference:** https://docs.ultralytics.com/datasets/segment/carparts-seg
- **Verified (Nov 2026):** 3,833 images (3,156 train, 401 val, 276 test), 23 classes (22 parts plus `object`), instance-segmentation masks in Ultralytics format. Download: `github.com/ultralytics/assets/releases/download/v0.0.0/carparts-seg.zip`, which was reachable from the build environment. The original source is Gianmarco Russo, "car-seg" (Roboflow Universe).
- **Licence: ambiguous.** The docs page footer links CC BY 4.0, while the dataset YAML header states AGPL-3.0. Until this is resolved, the images are not redistributed or deployed.
- **Downloaded and inspected (Nov 2026):** the 139.5 MB archive was fetched from the Ultralytics release URL in the build environment. It contains images and YOLO polygon labels, but no licence file; the only licence statement in the archive is the AGPL-3.0 comment in the YAML header.
- **Technical limit:** segmentation masks give component regions, not calibrated millimetre gaps. The gap between two masks in an uncalibrated photograph is not a physical measurement. If it is integrated later, it would be used only for component identification, with no mm values.

## 3. NIST design, manufacturing and inspection data for a box assembly (blocked)

- **Reference:** https://catalog.data.gov/dataset/design-manufacturing-and-inspection-data-for-a-box-assembly (DOI 10.18434/T4/1503154, landing page https://smstestbed.nist.gov/tdp/mtc, licence https://www.nist.gov/open/license).
- **Distribution:** `https://data.nist.gov/od/ds/73AE20D288CF02F1E05324570681502B1955/mtc.zip` plus a `.sha256` file.
- **Status:** the build environment's network policy refused the download (HTTP 403 from the egress proxy), and the landing page could not be fetched. Its file structure was therefore **not inspected**, and no parser or schema mapping was written, so nothing about its contents is assumed. Next step: download it locally, inspect the actual files, and add a separate `real` dataset with its own tables that are never linked to simulated units.

## 4. Bosch production line performance (not attempted)

- **Reference:** https://www.kaggle.com/c/bosch-production-line-performance/data
- **Status:** requires a Kaggle account and acceptance of the competition rules, and the data page did not render file details without sign-in. As specified, this optional track does not block the MVP. If it is used later, it would be an isolated ETL benchmark with no association with the synthetic units.
